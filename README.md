# Bitcoin Market Sentiment Analysis

This repository contains a data‑science project that explores the relationship between Bitcoin market sentiment and trader performance. It provides:

- Data loading and preprocessing utilities
- Exploratory data analysis notebooks
- Statistical testing scripts
- Visualizations of sentiment trends

## Getting Started

```bash
git clone https://github.com/yourusername/bitcoin-market-sentiment-analysis.git
cd bitcoin-market-sentiment-analysis
pip install -r requirements.txt
```

## Usage

Run the Jupyter notebooks located in the `notebooks/` directory to reproduce the analysis.
