# Bitcoin Market Sentiment Analysis

This repository contains a data‑science project that explores the relationship between Bitcoin market sentiment and trader performance. It includes:

- Data loading and preprocessing scripts
- Exploratory data analysis notebooks
- Statistical testing utilities
- Visualization helpers

## Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/bitcoin-market-sentiment-analysis
cd bitcoin-market-sentiment-analysis

# (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate

# Install required packages
pip install -r requirements.txt
```

## Running the analysis

Open the Jupyter notebooks in the `notebooks/` directory to reproduce the analysis.
