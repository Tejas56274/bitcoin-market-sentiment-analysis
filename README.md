# Bitcoin Market Sentiment Analysis

This repository contains a data‑science project that explores the relationship between Bitcoin market sentiment and trader performance. It includes:

- Data loading and preprocessing scripts
- Exploratory data analysis notebooks
- Statistical testing utilities
- Visualization functions

## Getting Started

1. Clone the repository.
2. Install the required packages listed in `requirements.txt`.
3. Open the Jupyter notebooks in the `notebooks/` directory to reproduce the analysis.

## Project Structure

- `data/` – raw and processed datasets
- `notebooks/` – exploratory analysis and results
- `src/` – reusable Python modules
- `tests/` – unit tests for the source code

Feel free to contribute by opening issues or pull requests.
